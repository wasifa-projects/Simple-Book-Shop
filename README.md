# Simple Bookshop Management System

My first course-related project in my undergraduate Computer Science and Engineering journey, developed using the C programming language for **CSE103 – Structured Programming**.

## About the Project

The Simple Bookshop Management System is a menu-driven console application designed to manage basic book information. It allows users to add books, view available book records, search for books by title, and check the total number of book entries.

This project was an early opportunity to apply fundamental C programming concepts to a practical problem.

## Features

- **Display Books:** View book titles, authors, prices, and available copy counts.
- **Add Books:** Enter book information, including title, author, price, and number of copies.
- **Search Books:** Search for a book using its title.
- **Count Book Entries:** Display the total number of book records entered.
- **Menu-Driven Interface:** Navigate through the available operations using a console menu.
- **Welcome and Exit Messages:** Display introductory and goodbye messages.

## Technologies Used

- **Programming Language:** C
- **Course:** CSE103 – Structured Programming

## Concepts Practiced

- Structures (`struct`)
- Arrays and strings
- User-defined functions
- Loops and conditional statements
- `switch-case` statements
- Console input and output

## Limitations

- Book records are stored in memory and are not saved permanently.
- The program supports a maximum of 50 book records.
- Book management is limited to the implemented menu operations.

## How to Run

1. Install a C compiler, such as GCC.
2. Save the source code as `main.c`.
3. Compile and run the program after ensuring compatibility with your compiler.
